# ENAJU

Workspace de projetos da ENAJU para estrategia institucional, pesquisa aplicada, produtos digitais, publicacoes, evidencias e entregaveis.

Repositorio central:

```text
https://github.com/cairesmachado-svg/ENAJU
```

Comece pela pasta:

[00_CENTRAL_ENAJU](00_CENTRAL_ENAJU/README.md)

Ela contem:

| Guia | Para que serve |
| --- | --- |
| [Como acessar](00_CENTRAL_ENAJU/01_COMO_ACESSAR.md) | Passo a passo para GitHub, download, Git e VS Code |
| [Organizacao visual](00_CENTRAL_ENAJU/02_ORGANIZACAO_VISUAL.md) | Onde guardar cada tipo de trabalho |
| [Rotina de trabalho](00_CENTRAL_ENAJU/03_ROTINA_DE_TRABALHO.md) | Como criar, revisar e publicar projetos |
| [Inventario atual](00_CENTRAL_ENAJU/04_INVENTARIO_ATUAL.md) | Mapa do que ja existe no workspace |
| [Repositorios existentes](00_CENTRAL_ENAJU/05_REPOS_EXISTENTES.md) | Projetos vinculados como submodulos |

Para abrir tudo no VS Code, use:

```powershell
code ENAJU.code-workspace
```

Para clonar com os projetos vinculados:

```powershell
git clone --recurse-submodules https://github.com/cairesmachado-svg/ENAJU.git
```
