# ENAJUCODE Evidências 001

Pasta consolidada dos arquivos relacionados ao produto **ENAJUCODE Evidências 001**.

## Estrutura

- `00_revisao/`: relatório final v1 para revisão. O arquivo `CODE_Evidencias_001.docx` foi mantido como referência de template base para os próximos relatórios.
- `01_insumos/`: arquivos de entrada, incluindo URL do YouTube e prompts usados na execução/formatação.
- `02_assets/`: imagens e recursos visuais associados ao relatório.
- `03_pipeline/`: repositório/pipeline usado para baixar áudio, transcrever o webinário e gerar relatórios automáticos.

## Observações

- Os artefatos automáticos do webinário continuam dentro de `03_pipeline/relatorios-enaju/transcricao_webinario/`.
- O relatório v1 em `00_revisao/` deve prevalecer como base editorial para revisão humana e padronização dos próximos produtos.
- A transcrição automática e a análise gerada pelo pipeline devem ser tratadas como insumo preliminar.
