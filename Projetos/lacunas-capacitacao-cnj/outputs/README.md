# Outputs

Entregaveis consolidados para leitura humana:

- `checklist_validacao.html`
- `resumo_por_documento.csv`
- `resumo_por_eixo.csv`
- `relatorio_validacao.md`
- `resumo_executivo.md`
- `resumo_executivo.docx`

Arquivos gerados localmente nao sao versionados por padrao. O checklist HTML e
a interface local recomendada para clicar, validar e baixar as filas
preenchidas. Enquanto a fila de revisao humana nao for importada, os documentos
sao marcados explicitamente como preliminares.
