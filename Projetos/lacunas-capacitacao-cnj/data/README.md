# Dados do Projeto

Os dados gerados nao sao versionados por padrao. Cada execucao deve registrar
data, configuracao e logs.

| Pasta | Conteudo |
| --- | --- |
| `raw_html/` | Snapshots datados do portal |
| `raw_pdf/` | PDFs aprovados para download |
| `text/raw/` | Texto extraido sem limpeza |
| `text/clean/` | Texto limpo com marcadores de pagina |
| `processed/` | Catalogos, status, corpus, segmentos e evidencias |
| `logs/` | Logs por etapa |
