# Projetos ENAJU

Use esta pasta para novas iniciativas que ainda estao sendo estruturadas ou que precisam de uma casa antes de virarem um projeto autonomo.

## Quando usar esta pasta

| Situacao | Acao |
| --- | --- |
| Nova ideia com escopo em formacao | Criar subpasta em `Projetos/` |
| Projeto com responsavel e entregavel definidos | Adicionar `ficha-projeto.md` |
| Projeto com codigo, dados ou produto recorrente | Avaliar se merece pasta propria na raiz |
| Projeto concluido | Mover entregaveis finais para `Outputs/` ou manter `Outputs/` dentro da subpasta |

## Estrutura Recomendada

```text
Projetos/
└── nome-curto-do-projeto/
    ├── README.md
    ├── ficha-projeto.md
    ├── Inputs/
    ├── Fontes/
    ├── Outputs/
    ├── docs/
    ├── dados/
    └── scripts/
```

## Primeiro Passo

Copie o modelo:

```text
00_CENTRAL_ENAJU/templates/FICHA_PROJETO.md
```

Depois preencha objetivo, status, entregaveis, responsavel e proximos passos.
