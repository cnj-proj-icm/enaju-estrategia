# Dicionários de dados

Esta pasta é **versionada** e guarda apenas metadados (sem microdados).

| Arquivo esperado | Conteúdo |
| --- | --- |
| `variaveis_piloto.csv` | Nome, descrição, tipo, valores permitidos, origem de cada variável |
| `dominios.csv` | Tabelas de domínio (categorias e rótulos) |

Convenção mínima de colunas para `variaveis_piloto.csv`:

```
variavel,descricao,tipo,valores_permitidos,obrigatoria,origem
```
