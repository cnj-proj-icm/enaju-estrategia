# Backlog ENAJU

Use esta pasta para guardar demandas, ideias e oportunidades que ainda nao viraram projeto.

## Como registrar uma demanda

Crie um arquivo Markdown com nome curto e claro:

```text
ano-mes-tema-da-demanda.md
```

Exemplo:

```text
2026-05-observatorio-escolas-judiciais.md
```

## Modelo Rapido

```markdown
# Titulo da demanda

## Contexto

## Por que importa

## Possivel entregavel

## Pessoas ou areas envolvidas

## Proximo passo
```

## Criterios de Priorizacao

| Criterio | Pergunta |
| --- | --- |
| Alinhamento | A demanda se conecta ao Art. 19 ou a estrategia ENAJU? |
| Impacto | Ajuda escolas judiciais, gestores ou a rede nacional? |
| Evidencia | Ha dados, normas, documentos ou parceiros disponiveis? |
| Entregavel | Pode gerar produto, relatorio, artigo, guia ou ferramenta? |
| Esforco | Cabe em um ciclo curto de trabalho? |
